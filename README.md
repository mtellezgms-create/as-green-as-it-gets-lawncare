# As Green As It Gets Lawncare LLC

Static, mobile-friendly website for a chemical lawn care company based in Van Alstyne, Texas.

## Deploy on GitHub Pages

Go to **Settings → Pages → Build and deployment → Deploy from a branch**, select **main** and **/(root)**, then save. Your website will be at https://mtellezgms-create.github.io/as-green-as-it-gets-lawncare/.

## Before public launch

- Replace the temporary typographic grass emblem with the owner's approved original logo.
- Replace the temporary externally hosted hero image with licensed/owned production photography.
- Connect a form provider (e.g. Formspree) and test submissions; the current form deliberately does not send information.
- Confirm the fire-ant guarantee terms, eligibility and permitted claims with the owner before advertising.
- Verify service territory, phone numbers, and any licensing disclosures required for pesticide application in Texas.
- Confirm all service descriptions and legal claims with the owner.

**Only specialty fire ant control has the 10–12 month guarantee.**
